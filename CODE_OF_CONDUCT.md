# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback, and do not harass, insult, or discriminate against anyone. Maintainers may remove comments, commits, or contributors that violate these standards.

Report unacceptable behavior by opening a private GitHub Security Advisory on this repository or contacting the maintainer (@SahinurDEV) directly. All reports are reviewed and kept confidential.
